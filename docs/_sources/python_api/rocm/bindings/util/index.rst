rocm.bindings.util
==================

.. py:module:: rocm.bindings.util

.. autoapi-nested-parse::

   ROCm Python bindings utility helpers.

   This package groups the low-level helpers shared across the ROCm
   Python bindings: device-array adapters and other data types,
   shared-library loading, and library path discovery.
